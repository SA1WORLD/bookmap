# ALKHULAIFI GOLD ORDER FLOW

Arabic PWA for XAU/USD price monitoring on iPhone and Android. Requires a user-supplied goldApi.dev key for prices; free plan allows 100 requests per hour; browser CORS compatibility has not been verified. No real order book, resting orders, or volume-based liquidity is provided. The price history chart is built from samples recorded while the app is open.

Deploy as a Render static site with build command `echo ready` and publish path `.`.
