# ALKHULAIFI GOLD ORDER FLOW

Arabic PWA for XAU/USD price monitoring on iPhone and Android. Requires a user-supplied GoldAPI.io key for prices; free access and CORS are not guaranteed. No real order book, resting orders, or volume-based liquidity is provided. The price history chart is built from samples recorded while the app is open.

Deploy as a Render static site with build command `echo ready` and publish path `.`.
